MAELINNE WEBSITE PREVIEW

Open index.html locally to view. To publish on a commercial-suitable static host, upload the ENTIRE contents of this folder (index.html, styles.css, script.js, assets).

GitHub repository can store the code. GitHub Pages should not be used to run an online store. Use a commercial-suitable website host such as Cloudflare Pages or Netlify after checking current terms.

IMPORTANT: This is a design / functional demo, NOT a live online shop. Example product images come from screenshots; example prices €22, €25, €27 are unverified and must be replaced with real inventory details before launch. Favourites and shopping bag are stored only in that browser using localStorage; there is NO checkout, stock management, accounts, or payment processing. The Instagram and Shopify buttons are PLACEHOLDERS pointing to provider homepages; update links to your actual MaeLinne accounts before publishing. Sign-up is not connected; connect a mailing-list service before announcing subscriptions.

To update products: edit inventory in script.js and the corresponding HTML shop-card titles/images/prices; replace images in assets/. For live commerce, connect Shopify Buy Button / Storefront API or another hosted checkout with real inventory; do not collect card details in this static site.
